# FindALead website

This is a mobile-first static website for FindALead.

## Included
- Responsive homepage
- FindALead navy/orange branding
- Multi-trade services
- How it works
- Trust/standards section
- Homeowner enquiry form
- Contact email: FindALead.org@yahoo.com

## Important
The enquiry form currently opens the visitor's email app and prepares an email to FindALead.org@yahoo.com. This is ideal for an MVP but should eventually be replaced with a proper hosted form/database so enquiries are captured even when visitors do not have an email app configured.

## Publishing
The folder can be uploaded to a static host such as Netlify, Cloudflare Pages, GitHub Pages, or similar. Your existing findalead.org domain can then be connected to that host.
